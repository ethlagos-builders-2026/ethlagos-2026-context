# Contributing

This is a shared two-person research repository for ETH Lagos 2026.

## Workflow

- keep main readable and accurate
- use short branches for meaningful research changes
- open a pull request when adding or changing important context
- cite primary sources
- mark unverified information as OPEN
- do not turn assumptions into rules

## Suggested branch names

- docs/event-update
- docs/sponsor-update
- docs/track-research
- docs/rules-update

## Commit examples

- docs: add hackathon track research
- docs: update sponsor bounty information
- docs: record submission deadline
- docs: clarify ERC-8004 context

## Current restriction

Do not add product-specific implementation or declare a final project until the team explicitly makes that decision.
