## Research rule

Prefer:
1. ETH Lagos official material
2. official Ethereum EIP/ERC documentation
3. official sponsor documentation
4. secondary sources only when the primary source is unavailable

If two sources conflict, record the conflict instead of silently choosing the convenient version.
