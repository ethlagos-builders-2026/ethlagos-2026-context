# Inspiration Builds

This file answers the research question: what kinds of builds are the ETH Lagos challenge descriptions pointing toward?

It does not choose our final project.

## Agents for the Real World

Organizer direction:
Autonomous AI agents doing useful economic labor on L2s with ERC-8004.

Possible build categories:
- autonomous procurement or commerce agents
- payment/settlement agents
- agent service marketplaces
- agents with portable reputation
- agent validation systems
- multi-agent coordination systems
- agents with bounded economic permissions

The common thread is that the agent should perform a useful task, not only chat.

---

## The "Invisible Crypto"

Organizer direction:
Consumer UX that hides crypto complexity through account abstraction and paymasters.

Possible build categories:
- gasless payment flows
- consumer wallets that feel like normal apps
- passkey-based onboarding
- mobile merchant checkout
- remittance experiences
- savings/contribution applications
- applications that batch or abstract multiple blockchain actions

The common thread is reducing the number of blockchain concepts the end user must understand.

---

## Sovereign Finance & Local RWAs

Organizer direction:
Connect onchain liquidity with off-chain Nigerian assets.

Possible build categories:
- receivable or invoice financing
- tokenized business obligations
- agriculture/warehouse-linked financing
- local asset liquidity systems
- onchain servicing records for real-world obligations
- products connecting verified cash flows to DeFi liquidity

The common thread is that the real-world side of the product must have a believable lifecycle.

---

## Decentralized Society

Organizer direction:
Censorship-resistant social tools and privacy technology tailored to Lagos.

Possible build categories:
- privacy-preserving community identity
- selective disclosure credentials
- censorship-resistant reporting/publishing
- community governance
- public-goods funding
- quadratic funding
- private eligibility proofs
- decentralized community coordination

The common thread is that decentralization or privacy should solve a real social/coordination problem.

---

## Cross-track signals from the event

Across the site, ETH Lagos repeatedly points toward:

- real Nigerian utility
- Ethereum infrastructure that enables the product
- mobile-first UX
- lower transaction cost through L2s
- account abstraction
- useful autonomous agents
- privacy
- real economic settlement
- public goods and community coordination

These signals should inform later research, but they are not a final project brief.
